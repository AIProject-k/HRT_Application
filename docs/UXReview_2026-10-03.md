## 이번 수정: 검사 날짜·시간 직접 선택

- `채혈 시간` 영역의 작은 `날짜 선택` 칩을 별도의 전체 너비 버튼으로 변경했다.
- `날짜·시간 직접 선택` → 달력의 `다음` → 시간 선택의 `확인` 순서로 입력한다.
- 버튼에 연도·날짜·시간을 표시하고, 직접 선택한 뒤에는 `날짜·시간 변경`으로 표시한다.
- `방금 받음`을 `방금 채혈`로 변경해 결과 수령 시각과 채혈 시각의 혼동을 줄였다.
- 날짜 선택기를 다시 열면 현재 선택된 채혈 시간을 기준으로 시작한다.
- 달력의 초기 날짜를 현지 날짜의 UTC 자정 값으로 변환한다. 서울 자정 직후 등의 경우 전날이 선택되던 문제를 수정했다.
- `오늘 오전`, `어제`, `시각 모름`의 기존 빠른 선택은 유지한다.

관련 파일: `app/src/main/kotlin/com/hormonelog/app/feature/lab/LabSheet.kt`, `feature/common/DateTimePicker.kt`.

## 후속 개선 우선순위

아래는 최초 검토에서 확인한 문제와 개선안이다. 사용자 승인 후 여섯 항목 모두 구현했다. 구현 결과는 문서 마지막에 기록한다.

### 1. 높음 · 검사값과 단위가 다르게 표시됨

위치: `app/src/main/kotlin/com/hormonelog/app/feature/dashboard/DashboardView.kt:80`, `:174`.

`labSubtitle`과 `nearestLabWithin`은 입력한 원래 수치를 가져오면서 E2 단위를 항상 `pg/mL`로 붙인다.
예를 들어 `1000 pmol/L`로 입력하면 기록에는 `1000 pg/mL`로 표시된다. 그래프의 마름모는 환산값을 사용하므로 숫자가 서로 달라 보일 수도 있다.

개선: 기록에는 원래 수치와 원래 단위를 함께 표시하고, 그래프 설명에는 그래프와 같은 환산 수치·단위를 사용한다.

### 2. 높음 · 잘못된 검사값을 알려주지 않거나 일부만 저장함

위치: `app/src/main/kotlin/com/hormonelog/app/feature/dashboard/DashboardState.kt:111`, `:581`, `:592`.

`canSave`는 공백 여부만 확인하고 숫자패드는 소수점을 여러 번 입력할 수 있다.
E2를 `1..2`, Total T를 `20`으로 입력하면 저장 버튼은 활성화되지만 E2는 버려지고 Total T만 저장된다.
E2에 `.`만 입력하면 저장 버튼이 활성화되지만 눌러도 저장되지 않고 이유도 표시하지 않는다.

개선: 잘못된 필드 옆에 오류를 표시하고, 모든 입력값이 유효할 때 저장을 허용한다. 두 번째 소수점도 막는다.

### 3. 보통 · 연도가 다른 기록이 같은 날짜 묶음으로 합쳐짐

위치: `app/src/main/kotlin/com/hormonelog/app/feature/dashboard/DashboardView.kt:17`, `:109`, `:122`, `:140`.

날짜 묶음의 키가 `8월 1일` 같은 표시 문자열이다. 2025년과 2026년의 같은 월·일 기록이 한 묶음으로 합쳐진다.

개선: 묶음은 `LocalDate` 또는 `yyyy-MM-dd`로 구분하고, 이전 연도의 기록에는 연도를 표시한다.

### 4. 보통 · 다음 투약 날짜가 사용자 일정 없이 추정됨

위치: `app/src/main/kotlin/com/hormonelog/app/feature/dashboard/DashboardView.kt:149`.

반복 일정이 없으면 7일 간격을 가정한다. 실제 일정이 다른 사용자에게도 `다음 투약`을 표시하며, 이미 지난 일정은 모두 `오늘`로 표시한다.
활성 일정이 여러 개이면 첫 번째 일정의 간격과 가장 최근 에스트로겐 투약이 조합될 수 있다.

개선: 사용자가 지정한 일정과 해당 약물의 기록을 연결해 표시하고, 미설정·예정·지난 일정을 구분한다.

### 5. 보통 · 과거 검사 입력 시 투약 간격 안내가 음수가 될 수 있음

위치: `app/src/main/kotlin/com/hormonelog/app/feature/dashboard/DashboardScreen.kt:102`, `feature/lab/LabSheet.kt:217`.

항상 전체 기록 중 최신 에스트로겐 투약을 기준으로 채혈 간격을 계산한다. 과거 검사를 입력하면 검사 이후의 투약이 기준이 되어 `약 -N일 뒤 채혈`로 표시될 수 있다.

개선: 선택한 채혈 시각 이전의 마지막 실제 투약을 기준으로 계산한다. 앞선 투약이 없으면 안내를 생략한다.

### 6. 보통 · 내보내기처럼 보이는 행이 눌리지 않음

위치: `app/src/main/kotlin/com/hormonelog/app/feature/me/MeScreen.kt:53`, `:212`, `:253`.

상단 `데이터 내보내기 ›` 행에는 클릭 처리가 없고, 실제 CSV 내보내기는 아래의 별도 버튼이다.

개선: 상단 행에서 바로 내보내기를 실행하거나, 중복 행을 제거해 진입점을 하나로 만든다.
