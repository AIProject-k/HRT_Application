**앱 잠금·지문·기록 암호화·백업 비밀번호는 만들었다가 뺐어요(2026-10-08, 요청).** 기록은 기기 안의 일반 파일이고, 백업 `.hlb`도 암호 없는 JSON이에요. 위장 모드(런처 이름·아이콘), 최근 앱 화면 가리기, 알림 문구 중립화는 그대로 있어요.

## 확인하다가 찾아 고친 것

- 고환 정보를 "말하고 싶지 않음"으로 두면 내 정보에 "Total T 예측에 사용"이라고 나오던 것 → "Total T 곡선을 그리지 않아요".
- 알림에서 "잠금 화면에서 내용 숨기기"를 꺼도 "항상 중립 문구"라고 나오던 것 → 켜짐/꺼짐에 맞는 문구.
- API 28의 3버튼 하단 바가 폰이 라이트면 앱이 다크여도 밝게 나오던 것 → 시스템 바가 폰이 아니라 앱 테마를 따라요.
- 홈 화면 위젯이 "Can't load widget"으로 뜨던 것(위젯 레이아웃에 쓸 수 없는 View를 썼어요) → 빈 `LinearLayout`으로 교체.
- 타임라인에서 "1개월"을 골라도 두 달 전의 접힌 월 카드가 남던 것(단위 테스트가 잡았어요).
- 위장 모드에서 알림 머리글에 "메모"가 뜬다고 알려 주던 미리보기 → 실제로는 "HormoneLog"가 떠서(API 36 에뮬레이터에서 알림을 펼쳐 확인) 미리보기와 안내 문구를 사실대로 고치고, 효과가 없던 권한 요청(`SUBSTITUTE_NOTIFICATION_APP_NAME`)과 코드를 뺐어요.
- 이상한 날짜·수치가 든 백업·CSV가 앱을 죽이던 것(서기 292278994년의 검사, 10000년 이후의 기록, CSV의 `+999999999`년) → 불러올 때 1900~2200년·유한한 수만 받고 나머지는 불러오지 않고 따로 보관해요(복원 미리보기에 건수가 보여요).
- "모든 기록 삭제"가 리포트 파일, 복원 전 자동 보관본, 읽지 못해 따로 옮겨 둔 파일과 기록을 남기던 것 → 함께 지워요(실행 취소 5초는 그대로). 리포트 파일은 1시간이 지나면 앱이 앞으로 올 때 지워요.
- 알림 버튼·위젯·알람이 기록 파일을 읽다 실패하면 파일 이름을 바꿔 치우던 것 → 화면 없이 읽는 쪽은 실패해도 그대로 두고, 저장 중 오류는 앱을 죽이지 않고 경고로 보여요.
- 백업 복원이 지금 켜 둔 위장·최근 앱 가리기·알림 중립을 슬쩍 끌 수 있던 것 → 켜 둔 것은 그대로 두고, 파일이 켜라고 하면 켜요.
- CSV 내보내기에서 메모가 `=`, `+`, `-`, `@`로 시작하면 엑셀이 수식으로 읽던 것 → 앞에 `'`를 붙이고 불러올 때 떼요.

## 시안과 달라진 것 / 결정한 것

- 샘플 데이터 넣기 기능은 뺐어요(시안에 없고, 온보딩이 대신해요).
- 주사는 시안처럼 한 칩이지만, 모델이 근육/피하를 구분해서 "주사 방식(IM/SC)" 선택을 하나 더 뒀어요.
- 투약 시트에 시안에 없던 "메모 · 선택"을 남겼어요(기존 기능 유지).
- 보정 한계는 엔진의 −50%~+100%를 그대로 두고, 화면 문구는 실제 값을 써요(시안의 ±40%는 자리 표시로 봤어요).
- 스피로노락톤 표기는 기존 "스피로노락톤"을 유지해요(시안은 "스피로놀락톤").
- 온보딩 첫 일정에는 항안드로젠을 고르게 하지 않아요(내 정보 › 반복 일정에서 따로 추가).
- 기존 병원 정보(클리닉)는 데이터를 보존하고, 시안의 "방문 메모·다음 진료"를 새로 더했어요.
- **앱 잠금(PIN)·지문·기록 암호화·백업 비밀번호는 뺐어요.** 온보딩의 "잠금" 단계, 내 정보의 잠금 설정, 잠금 화면이 없어요. 앞선 테스트 빌드가 암호화해 둔 기록 파일이나 비밀번호로 잠근 백업은 읽을 수 없어요(기록 파일은 지우지 않고 `records.corrupt-…`로 따로 보관해요).
- 알림은 시각이 정확하지 않은 알람(`setAndAllowWhileIdle`)이라 몇 분 늦을 수 있어요. 대신 ‘정확한 알람’ 권한이 필요 없어요.
- 위장 모드가 바꾸는 것은 런처 이름·아이콘, 최근 앱 화면의 이름, 알림·위젯의 문구예요. **앱의 진짜 이름(`HormoneLog`)은 바꾸지 못해요.** 알림 머리글과 휴대폰 설정의 앱 목록은 안드로이드가 매니페스트의 앱 이름을 읽어 그리고, 알림마다 다른 이름을 붙이는 권한은 시스템 앱 전용이에요. 앱 이름 자체를 "메모"로 바꾸면 해결되지만 위장을 끈 사람에게도 그 이름이 보이게 돼서 따로 정할 일이에요.

## 아직 안 한 것

- **영어 UI**: 문자열이 코드에 박혀 있어서 `strings.xml`로 옮기는 작업이 먼저예요. 시안의 영어 길이 검증 예시는 그때 같이 봐요.
- **Pretendard 글꼴**: 지금은 시스템 글꼴이에요. 번들하면 APK가 커지고 라이선스 표기도 늘어요.
- **실기기 확인**: 개인 기기에는 설치하지 않았어요.
- 접근성 점검(TalkBack으로 훑기)은 라벨과 터치 크기만 코드로 맞췄고, 직접 들어 보지는 못했어요.
- 릴리스 서명: `keystore.properties`가 없으면 릴리스도 디버그 키로 서명돼요. 남에게 나눠 주기 전에 전용 키가 필요하고, 코드 줄이기(R8)는 꺼져 있어요.

## 빌드·테스트

```bash
./gradlew testDebugUnitTest :app:lintDebug --offline
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest --offline
```

화면 테스트는 앱의 기록·설정을 지우고 시작해서, `-e wipeAppData yes`를 주지 않으면 시작하지 않아요. **전용 에뮬레이터에서만** 돌려요. 포트 번호는 기기를 알려 주지 않으니(다른 프로젝트의 에뮬레이터가 같은 포트를 쓸 수 있어요) 먼저 이름을 확인해요.

```bash
adb -s <에뮬레이터> emu avd name        # HormoneLog_… 인지 확인
adb -s <에뮬레이터> install -r app/build/outputs/apk/debug/app-debug.apk
adb -s <에뮬레이터> install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb -s <에뮬레이터> shell am instrument -w -e wipeAppData yes com.hormonelog.app.test/androidx.test.runner.AndroidJUnitRunner
```
