## 1. 앱 한 줄 소개

HRT(호르몬 대체요법) 투약과 혈액검사를 기록하면, 문헌 기반 약동학 모델로 **예상 E2·Total T 곡선**을 그려 주는 안드로이드 앱이에요. 검사값이 쌓이면 곡선을 내 몸에 맞게 보정해요.

- 사용자: 여성화 HRT 중인 사람(주로 한국, 트랜스젠더 커뮤니티). 건강·성별정체성 정보라 민감도가 매우 높아요.
- 플랫폼: Android 폰 (minSdk 28), Jetpack Compose
- 데이터: 기기 안에만 저장. 서버·계정·네트워크 없음.
- 언어: 한국어 우선, 영어 추가 예정

## 2. 꼭 지켜야 할 원칙 (디자인 제약)

1. **예상값과 실측값을 절대 섞지 않기.** 예상은 teal 곡선·띠, 실측은 노란 마름모. 숫자 옆에 항상 "예상" 또는 "실측" 라벨.
2. **예상값은 숫자 하나로 보여주지 않기.** 항상 중앙값 + 범위(예: `142 pg/mL · 범위 105–180`).
3. **용량 권고 금지.** "목표", "최적", "이상적인 범위", "용량을 늘리세요" 같은 표현이나 UI를 만들지 않기. 가이드라인 띠를 넣는다면 라벨은 "가이드라인 참고"로만.
4. **면책 문구 유지.** "참고용 추정 · 임상 검증 아님 · 용량 판단은 의료진과" 문구가 관련 화면에 계속 보여야 해요.
5. **근거 없는 곡선은 그리지 않기.** 모델이 없는 경로(젤 등)는 "곡선 없음 + 이유"를 보여주는 상태가 필요해요.
6. **프라이버시.** 알림·위젯·최근 앱 화면에 "호르몬", 약 이름, 수치가 그대로 드러나지 않는 옵션이 필요해요.

### 글자

### 컴포넌트

## 4. 전체 공통 요청

1. **라이트 테마 + 시스템 테마 따르기.** 다크·라이트 토큰 세트를 만들어 주세요. 예상(teal)·실측(yellow) 구분이 두 테마 모두에서 유지돼야 해요.
2. **대비 기준.** 모든 글자 4.5:1 이상(큰 글자 3:1). 특히 면책 문구와 캡션 색을 다시 잡아 주세요.
3. **터치 영역 48dp 이상.** 지금 타임라인의 "수정·삭제"가 11sp 글자라 너무 작고 붙어 있어요.
4. **이모지 아이콘을 벡터 아이콘으로 교체.** 하단 탭, 기록 종류(투약·놓침·검사), 액션 버튼.
5. **큰 글자 대응.** 시스템 글꼴 200%에서 잘리지 않게. 고정 높이 요소(입력칸 58dp, 숫자패드 46dp 등) 재검토.
6. **영어 길이 대응.** 한국어보다 1.3~1.5배 긴 문구가 들어가도 레이아웃이 버티게.
7. **연도 표기 규칙.** 올해가 아닌 날짜는 연도 포함. "방금"은 1분 이내, 이후 "N분 전".

## 5. 화면별 요청

우선순위: P0 = 먼저, P1 = 다음, P2 = 나중.

### P0-1. 첫 실행 온보딩 (신규)

지금은 기록 0건일 때 "지원되지 않는 경로예요"라는 틀린 안내가 떠요. 온보딩으로 대체해 주세요.

단계 제안:
1. 앱 소개 + 원칙(기기 안에만 저장, 참고용 추정, 용량 권고 안 함)
2. 지금 쓰는 약 (약물·경로·용량·간격) → 반복 일정 생성. 건너뛰기 가능
3. 언제부터 투약했는지 → 지난 투약을 기록할지 묻기 (개수·기간을 보여주고 확인)
4. 고환 유무 (있음 / 수술함 / 말하고 싶지 않음) → TT 예측에 사용
5. 검사 단위 선호 (E2: pg/mL / pmol/L, T: ng/dL / ng/mL / nmol/L)
6. HRT 시작 전 검사값이 있으면 입력 (선택)
7. 앱 잠금 켜기 제안 (선택)

필요한 상태: 각 단계 건너뛰기, 뒤로 가기, 나중에 내 정보에서 다시 하기. 기록이 0건인 홈의 올바른 빈 상태 화면도 같이.

### P0-2. 홈 개편

- 히어로: `예상 E2 142 pg/mL` + `범위 105–180` + "예상 · 실측 아님" 라벨
- TT 카드 추가 (현재 E2만 있음)
- 수치 타일: 다음 투약 / 마지막 검사(값 + 며칠 전) / 이번 주기 피크·트로프 예상
- "🔒 이 기기에만 저장" 칩: 암호화 여부에 따라 문구가 달라지게 (예: "기기 안에만 · 암호화됨" / "기기 안에만 · 백업 안 됨"). 자물쇠 아이콘이 암호화로 오해되지 않게
- 백업 리마인드 배너 상태 ("마지막 백업 32일 전")
- "투약 기록 · 1탭" 버튼: 실제로 1탭 기록이 되도록 "최근 조합 바로 기록" 버튼 + 시트 열기 분리

### P0-3. 투약 기록 시트

현재 문제와 요청:
- **패치 용량 단위**: µg/day 단위와 규격 칩(25 / 37.5 / 50 / 75 / 100 µg/일), 교체 주기(주 2회 / 주 1회) 선택. 지금은 "매(패치)"·"mg/일"만 있어서 잘못 입력돼요.
- **프리셋**: 하드코딩된 "사이프로테론 25mg" 대신, 실제로 자주 쓴 조합 상위 3개 (항해제 포함).
- **약물 바꿀 때**: 그 약물로 마지막에 쓴 용량을 채우고, 그 사실이 눈에 띄게.
- **시간**: 저장 후 항상 "지금"으로 돌아옴. 미래 시각 선택 불가. 과거 시각이 선택됐을 때 강조 표시.
- **반복 일정 모드**: 저장 후 "1회만"으로 돌아옴. 반복 모드일 때 시트 전체가 "일정 만들기" 모드임이 분명히 보이게.
- **용량 입력**: 잘못된 입력(소수점 여러 개, 빈칸) 오류 표시.
- **주사 부위** (선택): 왼/오른 허벅지·엉덩이·배 등 구조화 선택 + 최근 부위 표시.
- **투약 상태**: 투약함 / 늦게 / 놓침 칩 유지.

### P0-4. 검사 결과 시트 + 저장 후 결과 카드

- **T 단위 칩**: ng/dL · ng/mL · nmol/L (현재 ng/dL 고정)
- **채혈 시각**: 미래 선택 불가. "오늘 오전"은 현재 시각 이전일 때만 노출.
- **투약 후 경과**: 2일 미만이면 시간 단위 ("마지막 투약 후 10시간").
- **단위 실수 경고** (신규): 예상 대비 약 3.7배·0.27배면 "단위를 확인해 주세요 (pg/mL ↔ pmol/L)" 인라인 경고.
- **저장 후 "예상 vs 실측" 카드** (신규): 그 시점 예상값, 실측값, 차이 %, 주기 위치(피크 근처 / 트로프 근처), 보정에 쓰였는지 여부 + 안 쓰였다면 이유.

### P0-5. 백업·복원·보안 (신규)

- **전체 백업 만들기**: 기록·일정·병원 메모 모두 포함, 비밀번호 선택. 진행·완료·실패 상태.
- **백업에서 복원**: 미리보기(투약 N건, 검사 M건, 일정, 병원 메모, 건너뛴 행과 이유) → 확인.
- **CSV 내보내기·불러오기**: 같은 미리보기 흐름. "CSV는 일부 정보만 담겨요" 안내.
- **앱 잠금**: PIN / 생체 설정 화면, 잠금 화면.
- **위장 모드** (선택): 런처 이름·아이콘 바꾸기, 최근 앱 화면 가리기, 알림 문구 중립화 설정.
- **저장 실패 상태**: 저장 공간 부족 등으로 저장 못 했을 때의 경고 배너.

### P1-6. 예상 흐름 (그래프)

- 범위: 1주 / 1개월 / 3개월 / 6개월 / 1년 / 전체 (+ 직접 지정)
- 미래 구간에 **예정 투약 눈금** (빈 눈금)과 기록된 투약 눈금 (꽉 찬 눈금) 구분
- 눈금 색을 약물별로 (에스트로겐 / 항안드로겐)
- 검사값이 축 밖이면 축을 늘림
- 범례를 실제 그림과 일치시키기 (지금 범례는 💉/✕인데 그래프는 색 선)
- 상태 배지: "젤 N건은 곡선에서 제외", "경구·설하만 쓰면 T 예측이 낮게 나올 수 있어요"
- **정상상태 안내**: 용량·경로를 바꾼 뒤 "새 용량이 검사에 반영되려면 약 N주" (정보 제공 문구)
- 스크럽: 가로 드래그만 반응, 세로 스크롤은 페이지가 받게
- 접근성: 차트 텍스트 요약 ("지난 30일 예상 E2 90–310 pg/mL, 실측 2건")
- 실측/예상 비율 추이 작은 차트 (선택)

### P1-7. 반복 일정 관리

- 일정 목록: 약물·용량·간격·시작일·종료일·활성 여부
- 일정 **수정**, **오늘부로 종료** (지금은 삭제만 가능)
- 간격 자유 입력 (지금은 매일 / 이틀 / 매주 / 2주 칩만) + 요일 지정 + 투약 시각
- 시작일 기본값 = 오늘 (지금은 30일 전)
- 종료일이 시작일보다 빠르면 오류
- **일정 충돌 다이얼로그**: 같은 약물·경로 일정이 이미 있으면 "기존 일정을 이 날짜로 종료할까요?"

### P1-8. 모델 상태 · 근거 탐색기

- 보정에 **쓴 검사 / 안 쓴 검사 목록과 이유** (예: "채혈 시각 없음", "기록 시작 직후라 이전 투약 정보 부족")
- 보정 결과: "예상보다 약 40% 높게 보정" + 한계값에 걸렸을 때 경고
- 경로별 보정 상태 (경구 / 주사 각각)
- **근거 탐색기** (신규): 지금 곡선에 쓰인 파라미터와 출처(논문·버전), 근거 수준, 한계

### P1-9. 알림

- 알림 설정 화면: 주사일, 매일 복용, 검사 주기, 진료 예약
- 알림 디자인: 기본 문구 + 중립 문구 버전 ("오늘 기록할 항목이 있어요"), "투약 완료" 액션 버튼

### P1-10. 내 정보 / 설정 (실제 동작하게)

지금 "언어", "화면" 행은 눌러도 반응이 없어요. 실제 설정 화면으로:
- 테마 (다크 / 라이트 / 시스템), 글자 크기
- 단위, 12/24시간
- 언어 (한국어 / English)
- 고환 유무, 기준 검사값
- 백업·보안 진입
- 오픈소스 라이선스, 앱 버전
- 확인 다이얼로그 문구: "되돌릴 수 없어요" → "5초 안에 실행 취소할 수 있어요" 등 실제 동작과 맞게

### P2-11. 타임라인

- 필터: 종류 + 약물별 + 기간 + 메모 검색
- 매일 복용 기록은 월 단위로 접기 (기록이 수천 건이 될 수 있음)
- 기록 출처 배지: 직접 입력 / 일정 / CSV / 예시 데이터
- 수정·삭제를 큰 터치 영역으로 (스와이프 또는 행 메뉴)
- 순응도 요약 (이번 달 투약률, 놓친 횟수)

### P2-12. 병원 메모

- 삭제 확인 + 실행 취소 (지금은 확인 없이 바로 삭제)
- 출처 링크를 실제로 열리는 버튼으로
- 진료 예약일·처방 기록 연결

### P2-13. 병원 방문용 리포트 (신규)

A4 1–2장 레이아웃: 기간, 현재 일정, 그래프, 검사값 표, 투약 순응도, 모델·근거 버전, 면책 문구. 이미지 공유용 세로 버전도.

### P2-14. 홈 화면 위젯 (신규)

다음 투약 + "투약 완료" 버튼. 위장 모드면 약 이름·수치 숨김.

### P2-15. 기록 항목 확장 (선택)

증상·컨디션, 체중, 혈압, 재고(남은 앰플·알약, 소진 예상일), 추가 검사 항목(LH, FSH, 프로락틴, SHBG, 칼륨).

## 6. 산출물 요청

1. 디자인 토큰: 다크·라이트 색, 글자 크기 단계, 간격, 모서리 (Compose로 옮기기 쉬운 표 형태)
2. 컴포넌트 명세: 기존 컴포넌트 개선안 + 신규 (경고 배너, 미리보기 목록, 예상 vs 실측 카드, 설정 행, 잠금 화면, 다이얼로그)
3. 화면 시안: 폰 360×800dp 기준, P0 → P1 → P2 순서
4. 화면마다 상태: 빈 상태, 정상, 오류, 곡선 없음(모델 없음), 큰 글자
5. 한국어 실제 문구 (영어 길이 검증용 예시 일부)
6. 접근성 주석: 대비, 터치 영역, 스크린리더 라벨

## 7. 하지 않을 것

- 용량 추천, 목표 범위, "적정/최적" 표현
- 용량 what-if 시뮬레이터
- 신체 변화 예측
- 계정·클라우드 동기화 화면
